Header

Footer

Button

Card

Section

---

El contenido visible para el usuario estará en español.

---

## Comentarios

Cada componente comienza con un bloque descriptivo.

Ejemplo

Nombre

Descripción

Autor

Proyecto

---

## CSS

Utilizar variables CSS.

No repetir colores.

Cuando un componente dependa de la altura visible del navegador, preferir unidades de viewport dinámicas como `svh` en lugar de `vh` si la sección necesita responder a cambios de la interfaz móvil.

---

## Componentes

Cada componente debe tener una única responsabilidad.
