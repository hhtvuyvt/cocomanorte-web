# Arquitectura del Proyecto

## Nombre

COCOMANORTE Web

---

## Descripción

Sitio web institucional del Consejo Comunitario Mayor COCOMANORTE.

El objetivo del proyecto es ofrecer una plataforma moderna para comunicar la identidad del territorio, la cultura, los proyectos y las actividades comunitarias.

---

## Tecnologías

- Astro
- HTML5
- CSS3
- JavaScript / TypeScript (futuro)

---

## Filosofía

El proyecto busca:

- Simplicidad
- Alto rendimiento
- Fácil mantenimiento
- Componentes reutilizables
- Código documentado

---

## Organización

src/

components/

layouts/

pages/

styles/

assets/

---

## Flujo

Página

↓

Layout

↓

Componentes

↓

Estilos

---

## Principios

- No duplicar código.
- Cada componente debe tener una única responsabilidad.
- Mantener separados estructura, lógica y estilos.
- Documentar cada cambio importante.
